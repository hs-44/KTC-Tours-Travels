# KTC Tours & Travels website preview

This is a static HTML prototype for previewing the KTC homepage on GitHub Pages.

## Deploy on GitHub Pages
1. Create a new public GitHub repository, e.g. `ktc-tours-website`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/ktc-tours-website/`

## Important
- This is a static preview, not the final WordPress website.
- GitHub Pages cannot host WordPress/PHP or its database.
- The enquiry form opens WhatsApp to KTC number 7083887900; it does not save enquiries in a database or send email.
- Demo package cards and stock photos are placeholders. Replace them with confirmed KTC packages and original photos before launch.
- For the final self-managed website (add/edit tours and photos in an admin dashboard), deploy WordPress on managed WordPress hosting and connect your own domain.
